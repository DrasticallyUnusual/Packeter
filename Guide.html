Packeter runs on any OS that supports Python + Tkinter:

  • Linux — any distribution (tested on Arch Linux)

2. Installation

1

Clone or Download

git clone https://github.com/user/Packeter.git
cd Packeter

Or download the ZIP from GitHub and extract it.

2

Verify Python Version

python3 --version

Ensure Python 3.10 or newer is installed.

3

Run Packeter

python3 run.py

That's it. No dependencies to install.

3. Usage Guide

Launching

python3 run.py

The GUI window opens with the Packeter interface.

Downloading Packages

1

Enter a Command or URL

Type or paste any supported install command into the SOURCE field:

git clone https://github.com/user/repo.git
npm install express
pip install flask gunicorn
cargo install ripgrep
wsl --install -d ubuntu
https://example.com/install.sh
2

Set Output Folder (optional)

Change the output directory using the Browse button, or use the default output/ folder.

3

Click Download

Press Download or hit Enter. A job card appears showing real-time progress.

4

Generate Install Script

After successful downloads, select .sh or .bat format and click Generate Install Script. A ready-to-run install script is created in the output folder.

Format Selection

  • .sh (Linux/macOS) — generates a Bash script with set -e, colored output, and proper error handling
  • .bat (Windows) — generates a Windows Batch script with @echo off and error codes

4. Practical Examples

Example 1: Download a Python Project

# In Packeter source field:
pip install flask gunicorn requests

# Packeter downloads all wheels to output/downloads/
# Then generates install.sh or install.bat

Example 2: Offline Install Script via URL

# In Packeter source field:
https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh

# Packeter:
#   1. Downloads the script
#   2. Analyzes it (finds NVM_GITHUB_REPO, curl commands)
#   3. Downloads the NVM release tarball
#   4. Rewrites the script to use local files
#   5. Generates install.sh

Example 3: Ollama Offline Setup

# In Packeter source field:
curl https://ollama.com/install.sh | sh

# Packeter detects pipe pattern, downloads the script,
# analyzes function calls, resolves 10+ dependencies,
# and generates a rewritten install script.

Example 4: WSL Offline Install

# Step 1: Download WSL components
wsl --install -d ubuntu

# Packeter downloads:
#   - WSL MSI from GitHub releases (~247 MB)
#   - Ubuntu .appxbundle (~570 MB)

# Step 2: Generate install script
# Generates PowerShell commands for the offline machine

5. Log Files

Packeter maintains two log files in the output directory:

Query.log

Records every command or URL you submit:

2026-07-25 14:30:15 - git clone https://github.com/user/repo.git
2026-07-25 14:31:02 - pip install flask
2026-07-25 14:32:18 - wsl --install -d ubuntu

Log.log

Records every successful file download:

https://github.com/user/repo/archive/main.tar.gz - repo-main.tar.gz - 2.4 MB - /path/to/output/downloads/repo-main.tar.gz - 2026-07-25 14:30:16
pip install flask - Flask-3.0.0-py3-none-any.whl - 627.3 KB - /path/to/output/downloads/Flask-3.0.0-py3-none-any.whl - 2026-07-25 14:31:03

6. Troubleshooting

Common Issues

ProblemCauseSolution
"pip is not installed" Pip not in PATH Install Python with pip, or add it to PATH
"npm is not installed" Node.js not installed Install Node.js from nodejs.org
Download fails with timeout Large file or slow connection Retry; URL handler has 120s timeout
"Unsupported command" Command pattern not recognized Use a direct URL instead of the install command
WSL distro download is huge Distro .appxbundle can be 500+ MB Expected behavior; use a stable connection
Script analysis fails Complex/unusual shell syntax Downloads still work; install script just won't be rewritten

Getting Help

  • Check the Download tab in the GUI for real-time error messages
  • Review Query.log and Log.log in the output folder
  • Report issues at https://github.com/user/Packeter/issues
Tip: You can run multiple downloads in sequence. Each one appears as a separate job card. When all complete, click "Generate Install Script" to create a combined install script that handles everything.
